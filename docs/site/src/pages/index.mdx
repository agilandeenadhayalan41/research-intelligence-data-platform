<HomeSection
  id="a-governed-path"
  title="A governed path"
  intro="The data is large, it changes (records are updated and Works are deleted), and its many-to-many relationships make naive counts wrong. The platform's answer is a governed path with these properties."
  variant="steps">

1. **Bounded retrieval.** Source files are discovered from a public manifest and fetched one
   small, bounded file at a time, anonymously.
2. **Preserved source.** The original bytes are stored unchanged, with a SHA-256 checksum and
   provenance, so any step can be replayed.
3. **Portable canonical model.** Records are normalized into entities and relationships that do
   not depend on any one database engine.
4. **BigQuery analytics.** Analytical models are built in BigQuery. Gold marts (consumer-facing
   outputs) are materialized only when measured usage justifies it.
5. **Quality before visibility.** Hard data-quality gates must pass before anything becomes
   visible to consumers.
6. **Capabilities, not raw SQL.** Consumers use a storage-independent Data Service of domain
   capabilities, such as "look up a Work by DOI".

The whole path is followed stage by stage on [How it works](/overview/how-it-works).

</HomeSection>

<HomeSection id="where-things-stand" title="Where things stand" variant="note">

**What a consumer gets.** Typed questions instead of raw SQL, for example: look up a Work by
DOI, count the unique authors per journal, or follow publisher × topic trends by year. Today
these exist as tested contracts and query patterns. Their SQL has run in BigQuery on synthetic
data, and the Data Service capabilities run locally. None is deployed as a service yet.

All **21 roadmap steps are complete**. That means the planned contracts, local validation,
orchestration contracts and readiness assessment are done. It does **not** mean GCP deployment
is done, and it does not mean anything is production-ready.

Beyond the roadmap, the GCS and BigQuery adapters have passed live smoke tests in a sandbox
project and in personal projects labelled DEV and QA. The BigQuery models have been deployed and
measured there **on synthetic data only**. Every environment is still `NOT_READY` overall, and
every mandatory PROD domain is `BLOCKED`. The evidence levels and the open gaps are on the
[Status](/overview/status) page.

</HomeSection>
