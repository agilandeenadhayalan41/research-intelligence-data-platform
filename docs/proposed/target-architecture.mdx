:::caution[Proposed, not built]

This is the **proposed next architecture**: a schematic target, not a description of
what runs today. What exists today, and how strongly it is proven, is on the
[Status](../overview/status.md) page. Local and synthetic cloud evidence must not be read
as a production deployment. Where the diagram shows managed Airflow,
[ADR 0001 D6](../adr/0001-gcp-architecture-and-service-selection.md#d6-orchestration-cloud-workflows-triggered-by-cloud-scheduler)
proposes Cloud Workflows triggered by Cloud Scheduler instead, with Cloud Composer
only if DE-04 (#125) confirms a shared enterprise Composer environment.

:::

The diagram shows the GCP-first target in three bands:

- **Data engineering:** source to published consumer data. That covers OpenAlex ingestion jobs, GCS Bronze, canonical Parquet (Silver), BigQuery Silver and Gold, quality and lineage gates, a published version contract, and the Data API with a cache.
- **Operations:** managed Airflow, IAM and catalog, monitoring, and CI/CD with Sandbox → DEV → QA acceptance gates.
- **Downstream products:** analytics and BI, data science, ML/MLOps, a knowledge graph, embeddings and vector search, and grounded RAG. Each is a separate workstream that starts only after the data-engineering gate is passed.

Below the main diagram are three zoom views: the 9-unit Airflow DAG, the BigQuery OLAP publication path, and the downstream data products.
